# Community Library

A simple community-powered online library built with plain HTML, CSS, and JavaScript.

## Features

- Add a book with a title and author
- Remove books from the library
- Responsive royal blue and royal purple design
- Browser storage using `localStorage`

## Run locally

Open `index.html` in a browser, or serve the directory with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
